Trajet

Route bloquée, arrêt impossible (travaux) ? Les carrés de couleur sont les arrêts, les carrés blancs numérotés les points de passage de l'aller. Glisse un arrêt ou un point pour le déplacer, touche la carte pour ajouter un point, touche un point pour le retirer. « Calculer » montre le nouveau trajet (en pointillé) ; « Appliquer » le publie pour tout le monde.
